This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

# 1. Блок. Знакомство с Next.js:

- Проект инициализирован с помощью create-next-app с TypeScript, структура и названия директорий не изменены, все стандартные файлы присутствуют.
- Преобразована разметка главной страницы из html в jsx и перемещена в page.tsx. Отсутствуют теги class, незакрытые блоки и т.д.
- Все теги img заменены на встроенный компонент <Image /> и имеют src, height и width.
- Декомпозирована главная страница на компоненты с расширениями файлов .tsx, которые расположены в /components. Каждый компонент находится в своей папке.
- У каждого компонента свой .module.css, глобальные стили используются только в globals.css, конфликтов нет.
- Исправлены ошибки, которые появлялись при запуске.
- В проект установлена библиотека classnames.
- Перенесены статические файлы в папку public.
- Подключен шрифт Montserrat к проекту с помощью Google Fonts.
- Заменены обычные ссылки с помощью встроенного компонента <Link />.

# 2. Блок. React Refs:

- Клик по треку запускает его аудио, визуально отображается точка. В плеере отображаются актуальные данные.
- React-компонент с помощью useRef() использует возможности аудиоэлемента для управления воспроизведением: play/pause, громкость, перемотка, зацикливание. Pause останавливает трек, Play возобновляет воспроизведение, иконки корректно меняются. Точка начинает пульсировать только при проигрывании трека.
- Redux подключён, присутствует состояние текущего трека и его проигрывания.
- Внешний вид совпадает с макетом — цвета, размеры, отступы, иконки, анимации и плавность отображения соответствуют.
- Все компоненты разбиты логично, для каждого компонента создана отдельная папка (tsx + styles).
