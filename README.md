# 1. Блок. Знакомство с Next.js:

- Проект инициализирован с помощью create-next-app с TypeScript, структура и названия директорий не изменены, все стандартные файлы присутствуют.
- Преобразована разметка главной страницы из html в jsx и перемещена в page.tsx. Отсутствуют теги class, незакрытые блоки и т.д.
- Все теги img заменены на встроенный компонент <Image /> и имеют src, height и width.
- Декомпозирована главная страница на компоненты с расширениями файлов .tsx, которые расположены в /components. Каждый компонент находится в своей папке.
- У каждого компонента свой .module.css, глобальные стили используются только в globals.css, конфликтов нет.
- Исправлены ошибки, которые появлялись при запуске.
- В проект установлена библиотека classnames.
- Перенесены статические файлы в папку public.
- Подключен шрифт Montserrat к проекту с помощью Google Fonts.
- Заменены обычные ссылки с помощью встроенного компонента <Link />.

# 2. Блок. React Refs:

- Клик по треку запускает его аудио, визуально отображается точка. В плеере отображаются актуальные данные.
- React-компонент с помощью useRef() использует возможности аудиоэлемента для управления воспроизведением: play/pause, громкость, перемотка, зацикливание. Pause останавливает трек, Play возобновляет воспроизведение, иконки корректно меняются. Точка начинает пульсировать только при проигрывании трека.
- Redux подключён, присутствует состояние текущего трека и его проигрывания.
- Внешний вид совпадает с макетом — цвета, размеры, отступы, иконки, анимации и плавность отображения соответствуют.
- Все компоненты разбиты логично, для каждого компонента создана отдельная папка (tsx + styles).

# 3. Блок. TypeScript:

- Меню открывается и закрывается по клику, реализация выполнена через state.
- Треки берутся из моковых данных, структура UI полностью отражает данные, типы соблюдены, вывод корректный через map.
- Нельзя открыть более одного окна, переключается только нужная категория, стили соответствуют макету, активный фильтр выделен цветом.
- Фильтры строятся динамически на основе моковых данных, дубликаты отсутствуют.
- Типизация полная: все данные и props типизированы, any не используется.
- Все компоненты разбиты логично, для каждого компонента создана отдельная папка (tsx + styles).

# 4. Блок. Redux Toolkit:

- Кнопки переключают следующий и предыдущий трек в плеере.
- На последнем треке переход вперёд не происходит, на первом — назад.
- По завершении трека автоматически включается следующий либо выбранный по логике shuffle.
- Shuffle включается и выключается, иконка меняется, порядок треков определяется случайным образом.
- Loop работает корректно: кнопка подсвечивается, трек повторяется, режим отключается с визуальной сменой состояния.
- Полоса прогресса движется по времени, тайминг соответствует аудио, перемотка по клику работает.
- Корректно отображается текущее и общее время трека. Текущее время синхронизировано с воспроизведением.
- Слайдер работает корректно, изменения слышны и видны, UI соответствует макету.
- Все компоненты разбиты логично, для каждого компонента создана отдельная папка (tsx + styles).

# 6. Оптимизация производительности:

- Данные из API, используемые на странице, типизированы (Promise).
- После успешной авторизации данные сохраняются в LocalStorage.
- Неавторизованный пользователь не может поставить или снять лайк.
- UI отображает текущее состояние лайка, функциональность работает как в плеере, так и в списке треков.
- Присутствует корректная обработка ошибок: отображается осмысленное и понятное сообщение.
- Отображаются только избранные треки, неавторизованный доступ невозможен.
- Layout используется для страницы избранных треков, дублирование разметки и логики отсутствует.
- Функция обновления токена подключена ко всем запросам с авторизацией.

## Адаптивная верстка не реализована:

- В макетах (Figma) представлены только десктопные версии.

- Проект фокусируется на функциональности: Next.js, Redux, TypeScript, тестирование.

### Рефакторинг

- Нет закомментированного кода
- Модульная структура (компонент = папка с tsx + css)
- Понятные названия переменных и функций
- Декомпозиция: страницы → компоненты → утилиты
- Переиспользование: хуки, функции, стили
- Полная типизация без `any`

### Фича 1: Реализация skeleton

- Создан глобальный файл `skeleton.css` с анимацией `pulse`
- Реализованы скелетоны для:
  -- Списка треков (`TrackSkeleton`)
  -- Плеера (`BarSkeleton`)
  -- Фильтров (`FilterSkeleton`).

### Фича 2: Реализация всплывающих подсказок с помощью компонента `Toast`:

- Создан компонент `Toast.tsx` с двумя видами уведомлений:
  -- предупреждение при лайке, если не авторизован - локальное (компонентное) уведомление.
  -- предупреждение при потере интернет соединения - глобальное (системное) уведомление.
  -- предупреждение при восстановлении интернет соединения - глобальное (системное) уведомление.

- Поддержка типов: error, success, warning
